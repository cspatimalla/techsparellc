# TECHSPIRE LLC — Company Website

A responsive, single-page company website featuring FRINGO, an online friendship application concept.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

No build tools or package installation are required.

## Project structure
- `index.html` — page content and sections
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and dynamic footer year

## Before publishing
- Confirm the contact email `hello@techspirellc.com` is active and replace it if needed.
- Add your official business address, phone number, social links and legal details if you want them displayed.
- Replace the FRINGO showcase artwork with real app screenshots when available.
- Connect a backend or form service if you need contact-form submissions.
- Review all company claims and FRINGO feature descriptions for accuracy.

## Deployment
Upload the contents of this folder to any static website host (for example, GitHub Pages, Netlify, Vercel or your web hosting provider).
